# Online Quiz System – Java JSP & Servlets

## Overview
This is a Java-based Online Quiz System developed using JSP, Servlets, and JDBC.
The application allows users to take quizzes, view results, and manage quiz data.
It follows a basic MVC architecture and focuses on backend logic, data handling,
and debugging of Java web applications.

## Features
- User login and registration
- Quiz creation and management
- Multiple-choice questions
- Timer-based quiz (if applicable)
- Automatic score calculation
- Result display
- Session management
- Basic validations and error handling

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- HTML, CSS
- Apache Tomcat
- MySQL (or your database)

## Project Structure
- `/src` – Servlet classes and business logic
- `/WebContent` – JSP pages, CSS, JS
- `/WEB-INF` – web.xml configuration
- `/lib` – Required JAR files

## How to Run the Project
1. Clone the repository
2. Import the project into Eclipse / IntelliJ
3. Configure Apache Tomcat server
4. Create the database and tables
5. Update database credentials in the code
6. Run the project on the server
7. Access via `http://localhost:8080/online-quiz-system`

## What This Project Demonstrates
- Java web development using JSP and Servlets
- Backend logic and request handling
- Database connectivity using JDBC
- Debugging and fixing Java web issues
- Clean and structured Java code
